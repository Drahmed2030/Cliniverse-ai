# Cliniverse Platform Recovery & Recomposition v2

## Purpose
Cliniverse is being recomposed as a software product powered by a reusable NeuraOps intelligence core. Legacy capabilities are source material, not abandoned work and not automatically production-ready.

## Product rule
Do not revive legacy screens unchanged. Extract the useful primitive (content, workflow, calculator, simulation, integration contract), normalize it into the current design system and data contracts, then reconnect it to Today / Learn / Progress / Explore / Me.

## Operating layers
- Core Practice — ECG, Echo, Ward.
- Advanced Practice — Resuscitation, Handover, Code Lab, Pathway Replay, recovered decision/case experiences.
- Clinical Systems — Clinical Reference, calculators and source-linked tools.
- Institutional — cohorts, assignments, analytics, Connected Diagnostics, FHIR/DICOM/HL7/PACS boundaries and NeuraOps workflow intelligence.

## Recovered evidence on current repository
- 7 current Ward simulated cases plus 8 additional structured Ward templates.
- 6 BLS + 6 ACLS structured Code Lab lessons.
- Megacode v2 runner with VF / PE / Sepsis simulation scope.
- 7 actual cases in the legacy Clinical Library implementation.
- 2 Critical Care case definitions.
- 3 authored Weekly Clinical Pearl entries.
- 6 legacy medical calculators.
- Clinical Nexus, FHIR Integration, Teleconsult/PACS workflow and Code Blue foundations remain in source.

## Identity
The learner product should not describe itself as AI-generated, synthetic-by-engine, or as requiring human review. Safety, provenance, validation and auditability remain engineering responsibilities and internal evidence. Learner-facing copy describes the learning activity, source/attribution where appropriate, and its simulation/education boundary.

## Content Factory contract
Source/Legacy -> Normalize -> Validate -> Connect -> Publish -> Measure.

Each learning unit should eventually carry:
- stable content id + version
- modality and specialty
- source and reusable-rights metadata
- learning objective
- task/question definition
- explanation/debrief
- difficulty
- graph connections
- publication state
- performance telemetry definition

## Sites
ChatGPT Sites can serve as a rapid internal operating surface/prototype for the Content Factory, but canonical content definitions, rights/provenance, learner state and release contracts remain in the Cliniverse/NeuraOps code/data plane.
