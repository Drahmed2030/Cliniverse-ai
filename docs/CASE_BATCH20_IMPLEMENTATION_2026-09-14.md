# دفعة 20 — المحتوى وواجهة المعاينة

## ما أُنجز
أُنشئت 20 مسودة حالة قصيرة مميزة. كل مسودة تحتوي هدفًا وسيناريو مكتوبًا وسؤالًا وثلاثة خيارات وإجابة مقترحة وتفسيرًا ونقطة تواصل مع المريض وروابط مصادر للمراجعة.

هذه **microcases تحريرية**، وليست عشرين محاكاة كاملة أو عشرين دراسة ECG/Echo مرئية معتمدة. عدد الحالات المعتمدة طبيًا: صفر. عدد مجموعات الوسائط المربوطة: صفر. اعتماد المحتوى والإجابات يحتاج مراجعة مفصلة؛ اكتشاف المرجع لا يعني أنه يدعم كل عبارة.

5 موضوعات تعيد صياغة أصول قديمة: STEMI، فشل القلب الحاد، ارتفاع الضغط مع أذية الأعضاء، البوتاسيوم مع أذية الكلى، وإجهاد البطين الأيمن مع الاشتباه بالانصمام الرئوي. الموضوعات الـ15 الأخرى مسودات جديدة لسد الفجوات. بقيت النسخ التاريخية الثلاث دون تعديل.

## تحديث المصادر
جرت جولة اكتشاف مجمعة للمصادر الأولية في ESC وASE، وسُجل نطاق التحقق داخل sourceRegistry في content/medical/batch20.ts. لم تُنسخ الإرشادات أو وسائطها.

- فهرس ESC الحالي يدرج تحديثات 2026 لفشل القلب والتعريف العالمي الخامس للاحتشاء؛ لذلك لا نفترض أن الاكتفاء بمراجع 2023 يغطي كل التحديثات. تعذر جلب صفحة فشل القلب المباشرة؛ مراجعة النص الكامل ما زالت مطلوبة.
- عُثر على صفحات ESC الخاصة بمتلازمات الشريان التاجي والرجفان الأذيني واعتلال العضلة والصمامات واضطرابات النظم والتامور.
- فُتح مستند ASE 2025 لوظيفة البطين الأيسر الانبساطية، وعُثر على مستند 2025 لتقييم القلب الأيمن.
- تبقى مراجع إضافية محددة ضرورية لفرط البوتاسيوم وتشخيص الانصمام الرئوي وجودة/قياسات Echo. هذه الفجوات ظاهرة في التفسيرات وليست مغطاة بادعاء عام.

## الواجهة
المسار المحلي: /labs/case-batch-preview. يعيد notFound خارج NODE_ENV=development، بما في ذلك بناء الإنتاج وVercel Preview المعتاد. ليس قسمًا عامًا جديدًا في التطبيق.

قائمة قابلة للتصفية → الحالة → السؤال → التفسير والمراجع. تُحفظ الإجابة والتصفية في ذاكرة الجلسة عند التنقل؛ التحديث الكامل يمسحهما. لا نقاط أو صلاحيات أو حفظ لحساب المستخدم.

تنفيذ الواجهة يشمل:
- أزرار بحد أدنى 48px، التفاف النص، بطاقات بارتفاع يتبع المحتوى.
- نافذة شرح native dialog واحدة، زر إغلاق، Escape وإرجاع التركيز.
- خطوات في URL hash واشتراك بأحداث الرجوع؛ توجيه التركيز لعنوان الحالة عند الانتقال.
- إعادة عرض السيناريو داخل السؤال باستخدام details دون نافذة إضافية.
- تباعد safe-area، شبكة متكيفة، ألوان دلالية للوضعين، ودعم تقليل الحركة.
- لا شريط إجابات ثابت يغطي المحتوى، ولا إرفاق ملفات مرضى أو تشغيل API قديم.

## المتبقي دون إعادة عمل منجز
1. تشغيل الفحوص البصرية الستة ومعالجة نتائجها؛ لا إعادة للجرد أو الاستخراج.
2. مراجعة طبية على مستوى العبارات والإجابات، واستكمال المصادر الناقصة وإثبات المراجعة البشرية.
3. إثراء المسودات القصيرة إلى الحالات المستهدفة الكاملة، وربط الوسائط المرخصة المطابقة لكل حالة وفق العقود الموجودة؛ لا نسخ أو استبدال أعمال Echo السابقة.
4. دمج الرحلة في الواجهة الحالية بعد تحقق المحتوى والواجهة، مع حفظ تقدم حقيقي عبر المسارات المعتمدة فقط.
