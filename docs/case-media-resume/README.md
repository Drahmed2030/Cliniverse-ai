# استئناف حزمة الوسائط

استؤنف العمل من `qa/case-batch20-cloud` عند
`ce5c673323056eca2f1f62b27d22aa00035ea7c9`، مع التحقق من تطابق HEAD المحلي
والبعيد عند بداية هذه الحزمة. تعديل تقرير الواجهة السابق محفوظ دون تغيير.

## ما أُنجز

- إضافة فحص محلي للعشرين حالة يستعمل بيانات الحالات والربط الحالية دون إنشاء عارض جديد.
- حفظ نسخة أدلة الجاهزية لخمس حالات Echo من commit
  `fa820b345e85bb8e541d5400e36c48516abba62e`، مع مسار كل ملف وبصمة Git الخاصة به.
- مقارنة محتوى السجلات الخمسة مباشرة بالنسخة الأصلية عبر Git؛ تطابق 5/5.
- التحقق من بصمة فيديو A4C الموجود باستخدام مسار العارض الحالي.
- إخراج تقرير JSON يربط كل مرشح بأدلته وموانعه، ويكشف تعارض الربط أو الحالة غير المعروفة.

هذا استكمال تقني لتجهيز الربط، وليس ربطًا لوسائط جديدة أو إغلاقًا لحزمة الوسائط.
لا تتضمن هذه الخطوة مراجعة طبية أو قانونية جديدة؛ سجلات المصدر محفوظة كما كانت.

## نتيجة المخزون

| الفئة | العدد | المطلوب التالي |

| A4C تكميلي | 1 | يبقى ضمن العارض المقيّد؛ لا يثبت مرضًا أو جاهزية إصدار كاملة |

| الحالة | العائق المحدد في الأدلة |
| --- | --- |
| DCM | المراجعة السريرية والخصوصية وتشغيل الجهاز غير مكتملة |
| HCM | المراجعة السريرية والخصوصية والتشغيل والاعتماد بعد الاشتقاق معلّقة |

الأربعة ذات البصمة. وجود وصف الاشتقاق أو نجاح هندسي قديم ليس وجودًا للملف
المطابق في فرع التطبيق، ولا اعتمادًا سريريًا له. لا تُفعّل الروابط اعتمادًا على هذا التقرير.

## التشغيل والتحقق

من جذر المستودع، باستخدام Node 24 المتاح في البيئة:

```bash
node scripts/report-case-media-readiness.mjs
node --test tests/case-media-bindings.test.mjs tests/case-media-return.test.mjs tests/case-batch20.test.mjs
```

النتيجة المنفذة: 9 PASS، صفر FAIL، صفر SKIP. فحص ESLint للسكربت ناجح.
نسخة المخرجات محفوظة في `media-readiness-report.json`؛ تُعاد توليدها عند تغير الربط.
تتوقف الأداة عند تعارض معرفات الحالات أو فقد دليل مرشح أو اختلاف بصمة DCM
المسجلة أو بصمة فيديو A4C المثبت. فحوص الشكل هذه لا تعوض مراجعة الوسائط نفسها.

لم تتغير الواجهات أو البيانات السريرية أو سياسات الحساب. لم يُشغّل بناء سحابي
أو اختبار متصفح جديد لهذه الحزمة؛ لم يحدث دمج أو نشر إنتاجي.

## نقطة الاستكمال

1. استعادة ملفات Echo المشتقة الموجودة سابقًا، ومطابقة SHA-256 قبل أي تثبيت.
   عند غيابها، استخدم وصف التحويل الأصلي والمصدر المثبت؛ لا تنشئ مشتقًا مختلفًا بصمت.
2. استكمال مراجعة الوسيط ذاته وتوافقه مع هدف الحالة، مع اختبار تشغيل الجهاز.
   اعتماد النصوص العشرين لا يغطي هذه المراجعات.
3. لدفعة ECG، استخدم PTB-XL المحدد في البحث السابق واختَر سجلات فعلية
   قابلة للمطابقة، مع حفظ الترخيص والبصمة ومعايرة العرض. لم يُختَر سجل جديد هنا.
4. يبقى عمق Ward وربطه بالحالات وAtlas والتحقق المتكامل للإصدار عملًا لاحقًا؛
   نجاح هذا الفحص لا يُغلقه.
